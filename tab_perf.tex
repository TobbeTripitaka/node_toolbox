Table~\ref{tab:perf} lists execution times on Apple M2 Max, 12 cores (Python 3.12.7, ObsPy 1.4.2, pandas 2.2.3, NumPy 2.5.3). Reading a 31-minute, 500-sps DLD component (2.8~MB) takes 44~ms, about 42\,000 times faster than real time. One day of 1000-sps data (about 265~MB per component) takes about 4~s. Log parsing is the slowest step, at about 0.8~s for a two-week log with 9920 records, but it runs once per node and the deployment and waveform index tables can be cached as CSV.
